# Literature Search

This folder contains the scripts and supporting files used to reproduce the literature search conducted for the accompanying review.

The literature search was performed using the OpenAlex REST API and targeted publications related to generative AI methods applied to high-dimensional biological data. The search covered journal articles published between 2015 and 2025.

## Files

- `search_openalex.py` - Performs the OpenAlex literature search, processes the retrieved records, and generates publication statistics used in the study.
- `figure1_provenance.txt` - Documents the search parameters, retrieval date, inclusion criteria, and other provenance information associated with the literature search.

The complete Boolean search query and literature selection methodology are provided in the manuscript and Supplementary Material.
