# VAE Synthetic Data - IBD Dataset

This folder contains the synthetic datasets generated by the Variational Autoencoder (VAE) for the IBD (GDS1615) dataset used in the comparative evaluation.

## Synthetic Data

Five synthetic datasets are provided, corresponding to five independent training runs of the VAE. These files were used to evaluate the consistency and quality of the generated data across independent model runs.

Each synthetic dataset can be compared with the empirical `GDS1615Dataset.csv` dataset provided in the `Dataset` folder.

## Evaluation

The synthetic datasets were evaluated using the following quantitative metrics:

- Subspace Cosine Similarity (SCS)
- Kullback-Leibler Divergence (KLD)
- Maximum Mean Discrepancy (MMD)
- Wasserstein Distance

The evaluation script `Compute_SCS_KLD_MMD_Wasserstein_Metrics.py` provided in this repository can be used to reproduce the quantitative evaluation for each of the five synthetic datasets.

The reported results in the accompanying study are summarized as the mean and standard deviation across these five independent runs.
