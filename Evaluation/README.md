# Quantitative Evaluation Metrics

This folder contains the script `Compute_SCS_KLD_MMD_Wasserstein_Metrics.py`, which implements the quantitative metrics used to compare the empirical and synthetic biological data in the accompanying study.

## Evaluation Metrics

The script computes four complementary measures:

- **Subspace Cosine Similarity (SCS)** - Measures the similarity between the subspaces represented by the empirical and synthetic data.
- **Kullback-Leibler Divergence (KLD)** - Compares the distributions of pairwise distances between empirical and synthetic samples.
- **Maximum Mean Discrepancy (MMD)** - Measures distributional differences between the empirical and synthetic datasets using a kernel-based comparison.
- **Wasserstein Distance** - Measures the distributional distance between empirical and synthetic data based on the transport required to align the two distributions.

Together, these metrics provide complementary assessments of geometric and distributional similarity between the empirical and generated samples.

## Usage

The script can be applied to synthetic datasets generated by the representative generative models evaluated in the study. Model-specific synthetic data files and additional instructions for reproducing the reported results will be added to this repository.
