# scDiffusion Synthetic Data - IBD Dataset

This folder contains five synthetic datasets generated by scDiffusion for the IBD (GDS1615) dataset used in the comparative evaluation.

## Synthetic Data

The five files correspond to five independent training runs of scDiffusion. Due to GitHub file-size limitations, the synthetic datasets are provided in compressed format. Each archive should be extracted before running the evaluation scripts.

The extracted synthetic datasets can be compared with the empirical `GDS1615Dataset.csv` dataset provided in the `Dataset` folder.

## File Extraction

Each `.zip` archive contains the synthetic dataset from one independent model run. Extract all five archives before executing the evaluation script.

## Evaluation

The five synthetic datasets were evaluated using:

- Subspace Cosine Similarity (SCS)
- Kullback-Leibler Divergence (KLD)
- Maximum Mean Discrepancy (MMD)
- Wasserstein Distance

The script `Compute_SCS_KLD_MMD_Wasserstein_Metrics.py` provided in the `Evaluation` folder can be used to reproduce the quantitative evaluation after extracting the synthetic data files.

Results reported in the accompanying study are summarized as the mean and standard deviation across the five independent runs.
